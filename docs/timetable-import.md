# 课表截图导入验收

2026-10-29 新增课表截图专用入口，复用已配置的 MiMo / OpenAI 兼容视觉服务，不把课表当作 DDL 解析。

识别输出为课程列表与歧义。课程包括名称、星期、HH:mm 开始结束、原文证据、逐项歧义。无作息表不得按节次猜时间；缺失字段为空，用户须补全或取消勾选。缺少证据或模型输出开始结束矛盾时清空时间。无 Key 返回明确演示标识及空列表，不伪造 OCR。

用户选择目标周（周一起始），确认该周的单双周、停课等规则；仅将选定记录作为该周具体日期的固定课程追加。不会替换课表、自动推广全学期、自动移动任务或已确认会议。预览展示重复项、与课程和会议的冲突、原任务冲突；原计划受影响时会标记无效，需重新排程。

新增 TimetableImport 保存当前用户的确认记录及原文证据，关联生成的 BusyInterval ID；老表不变，启动时 create_all 添加新表。导入事务与请求幂等复用原机制，预览指纹变化时返回409。

实际自动验收：44项测试通过，TypeScript与Vite生产构建通过，完整输出见 timetable-check-output.txt。新增测试覆盖预览不写库、确认持久化、任务计划失效/重新求解、每周旧课去重、批次内去重、时间/星期/空名称/空列表校验、缺失确认、过期预览、导入记录隔离、演示截图不识别、非法文件头、视觉请求与作息补充、缺失时间不补全。PNG测试载荷仅用于mock，不把模拟结果描述成真实模型输出。

此轮未用用户真实课表请求外部模型；截图复杂布局下的漏识别与模型错误仍须人工校对。没有新增依赖。

浏览器实际验证了个人日历中的“课表截图导入”和“课程与可用时间”入口均可见，并观察到课表识别确认对话框、图片选择、作息补充、目标周、手动课程及预览按钮。没有选择或提交用户的图片，没有改变现有课表与任务。运行服务已更新，用户可直接上传自己的课表。页面截图见 timetable-import.png。
