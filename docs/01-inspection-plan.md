## 预期风险与处理

| 风险 | 处理 |
|---|---|
| 时区、边界与取整 | 含时区 ISO 8601，统一转上海时间，半开区间；可用区间向内取整 |
| 组合约束不可行 | 不放宽硬约束，不返回伪可行计划，保存诊断 |
| 最小扰动被优先级压过 | 分阶段求解并锁定已证明最优的较高目标 |
| 并发确认、重复创建 | SQLite 写事务、幂等键、唯一索引与邀请状态校验 |
| 视觉模型臆测日期 | 完整日期证据检查、歧义标注、人工确认；失败可手动录入 |
| 本地原生依赖兼容 | 固定已实际导入与测试的版本，保留依赖快照 |
| 演示身份与真实鉴权混淆 | 明确标注可切换的本地合成身份；默认仅监听回环地址 |

实现过程曾发现较新 SQLAlchemy / pandas 原生轮子被 Windows 应用控制拦截；固定为已验证版本后解决，没有关闭操作系统保护。基础健康检查与 Vite 页面返回 HTTP 200 后才继续实现算法。
