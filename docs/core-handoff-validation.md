## 本轮新增覆盖

| 核心行为 | 实际验证 |
|---|---|
| DDL容量不足 | 返回所需240分钟、可用180分钟，不返回违约排程 |
| 依赖链、循环、缺失依赖、重复ID | 明确错误类型；依赖链赶不上截止时不错误声称已排好 |
| 优化目标顺序 | 高优先级新偏好不会牺牲最少移动目标 |
| 求解预算 | 零预算是 unknown 而非 infeasible；后续阶段超时保留已验证可行解 |
| 预检正确性 | 固定随机种子生成40组小实例，以独立穷举搜索对照 CP-SAT 可行性，全部一致 |
| 统一日程权限与范围 | 未登录401；不能通过 owner 查询他人；带时区、7天和数量上限校验 |
| 跨模块显示 | 已确认会议纳入日程；待确认邀请单独列出；会议确认后读取个人修复结果 |
| 失效计划 | 新课程冲突使 plan.valid=false、repair_needed=true，旧任务标为 stale |
| 导入周显示 | 超出原排程窗口的12月课程仍能读取；查询从课中开始时保留实际课程起止 |
| 缓存与隐私 | ETag/304，匿名缓存请求仍401；响应不含任务证据或访问令牌 |
| 默认窗口与截断 | 默认服务器今天；查询不创建计划；limit 截断显式提示；DDL半开范围无重复 |
| 协商备选边界 | 起点带秒数时向上取整，候选不早于请求起点 |
